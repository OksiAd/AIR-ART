# ПОЛЕ
Прототип арт-платформы: кураторская подборка → работа и автор → демо-бронирование.

## Запуск
`npm ci`, затем `npm run dev`. Сборка: `npm run build`.

React + Vite + Tailwind CSS. Button и Dialog скопированы из официального реестра shadcn/ui (new-york), используются в интерфейсе. Настройки в components.json. Компоненты shadcn/ui распространяются по MIT: https://github.com/shadcn-ui/ui/blob/main/LICENSE.md.

Авторы, работы и изображения — демонстрационные. SVG-иллюстрации созданы для проекта. Формы не отправляют персональные данные. Бронь сохраняет только ID работы и дату в localStorage; это не реальное резервирование, оплаты нет. QR ведёт на конкретную работу с открытием бронирования. Чтобы включить реальные заявки, нужны сервер, база, правила доступности, уведомления и обработка персональных данных.

Сценарии мерча и тиражной графики остаются за пределами первой итерации.

## Вторая итерация
Тёмная тема, оригинальная анимация материи (MP4 и GIF, статичный постер для reduced motion), шесть вымышленных авторов. Кураторский текст и словарь: Харман, Мортон, Брайант, Богост.

Маршруты: `#/authors`, `#/author/<id>`, `#/work/<id>`, `#/collaboration/<id>`, `#/shop`, `#/collaborations`. Страницы магазина и общего раздела коллабораций — заглушки. Заявки на коллаборацию демонстрационные, не отправляются и не сохраняют персональные данные.

`npm test` собирает проект и проверяет основные сценарии в JSDOM: шесть работ и авторов, словарь, валидацию и подтверждение заявки, заглушки и бронирование по QR-ссылке. Это не визуальная проверка в браузере.

## Проекты и Воркута
Главная страница — каталог из двух проектов. `#/project/ooo` сохраняет первую демо-подборку, `#/project/vorkuta` — «В каждом из нас», куратор Оксана Виноградова. Восемь участников из предоставленного списка. Кураторский текст и даты из материалов пользователя; персональные биографии, цены и авторство конкретных работ не выдумываются.

Обложка адаптирована по присланной афише. Фотографии работ и фрагментов (без людей) с предоставленного альбома: https://aleksandraptitsa.ru/disk/24-09-2026-v-kazhdom-iz-nas-ng6p2m. Ссылки на исходные кадры в `public/vorkuta/credits.json`. Шрифт Cormorant Garamond локальный, лицензия OFL в public/fonts.

Страницы участников `#/author/vorkuta-<id>`, формы заказа `#/order/vorkuta-<id>`. Выставка завершена: вместо бронирования — запрос на приобретение с согласованием цены, доступности и доставки. Контакты художников и получатель заказов не предоставлены, поэтому форма честно готовит скачиваемый черновик без отправки и без хранения персональных данных. Для реальных заказов нужен адрес получателя и обработчик заявок.

## Визуальная система
Направление по референсу https://pink-elephant.co/: чёрный фон, гротеск Manrope, крупный центрированный заголовок, фиолетово мерцающая метаморфоза ветви и камня, округлые карточки и компактные оранжевые акценты. Изображения и материалы референса не используются: анимация и контент проекта собственные. Стили — src/reference.css. Афиша Воркуты сохранена внутри проекта. Manrope поставляется локально по лицензии OFL в public/fonts.

## Анимация и типографика
Главная: «Разные оптики. Общее поле.». Оригинальный бесшовный цикл: камень → ветка → птица → узел → камень, 10 секунд / 240 кадров / 24 кадра в секунду. Цвет движется по поверхности и по полному цветовому кругу от фиолетового через синий и обратно в фиолетовый. Исходный генератор: scripts/render-metamorphosis.py (numpy, scipy, Pillow, ffmpeg). MP4 для веба, GIF-версия для совместимости, статичный постер и reduced motion, кнопка паузы.

Карточки проектов имеют общую высоту; типографическая пара — пластичная Cormorant Garamond для заголовков и строгая Manrope Light для текста. Оригинальные линейные знаки в src/components/concept-mark.jsx: оптические орбиты для ООО, след рельефа для Воркуты.

## Орбитальная композиция проектов
Фраза «Искусство начинается с вопроса» — крупный центрированный типографический блок. Проекты размещены независимо по диагонали, с собственными мягкими ореолами. SVG-контуры обложек напоминают минималистичные органические штампы. Сохранены изображения, названия, описания, статусы и переходы. Очень медленное плавание останавливается при наведении/фокусе и отключается через prefers-reduced-motion. На телефоне сохраняются боковые смещения без наложения текста. Стили: src/orbits.css.

Обложка Воркуты уменьшена и закреплена во внутренней маске: графичный контур угольного шлака с асимметричными изломами и небольшими порами. Переход — «Открыть выставку». Чёрный фон дополнен сдержанными радиальными переходами сложных дымчатых оттенков; светлые страницы выставки сохраняют собственный фон.

## Березичи / третий проект
`#/project/berezichi` — арт-резиденция в национальном парке «Угра», Калужская область. Карточка встроена в орбитальную композицию главной. Информация сверена с https://berezichi-air.ru/, страницами /team и /locations; Instagram https://www.instagram.com/berezichi_air/ добавлен как официальный ресурс пользователя.

Страница представляет архив сезона 21–31 августа 2026 года, не открытый набор. Форматы, локации, имена участников и грантополучателей, команда и контакт взяты с официального сайта. На сайте указано 10 мест в условиях, а в опубликованном списке имён — 9 участников и 3 грантополучателя; сохранены два опубликованных списка без выдуманного общего числа. Работы и продажи участникам не приписываются.

Фотографии с сайта сохранены локально с исходными ссылками в public/berezichi/credits.json. Тест verify-berezichi.cjs проверяет переход из третьей карточки, разделы страницы, списки, изображения, официальные ссылки и возврат к проектам.
