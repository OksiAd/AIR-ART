# ПОЛЕ
Прототип арт-платформы: кураторская подборка → работа и автор → демо-бронирование.

## Запуск
`npm ci`, затем `npm run dev`. Сборка: `npm run build`.

React + Vite + Tailwind CSS. Button и Dialog скопированы из официального реестра shadcn/ui (new-york), используются в интерфейсе. Настройки в components.json. Компоненты shadcn/ui распространяются по MIT: https://github.com/shadcn-ui/ui/blob/main/LICENSE.md.

Авторы, работы и изображения — демонстрационные. SVG-иллюстрации созданы для проекта. Формы не отправляют персональные данные. Бронь сохраняет только ID работы и дату в localStorage; это не реальное резервирование, оплаты нет. QR ведёт на конкретную работу с открытием бронирования. Чтобы включить реальные заявки, нужны сервер, база, правила доступности, уведомления и обработка персональных данных.

Сценарии мерча и тиражной графики остаются за пределами первой итерации.
