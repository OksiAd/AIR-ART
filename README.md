# ПОЛЕ
Прототип арт-платформы: кураторская подборка → работа и автор → демо-бронирование.

## Запуск
`npm ci`, затем `npm run dev`. Сборка: `npm run build`.

React + Vite + Tailwind CSS. Button и Dialog скопированы из официального реестра shadcn/ui (new-york), используются в интерфейсе. Настройки в components.json. Компоненты shadcn/ui распространяются по MIT: https://github.com/shadcn-ui/ui/blob/main/LICENSE.md.

Авторы, работы и изображения — демонстрационные. SVG-иллюстрации созданы для проекта. Формы не отправляют персональные данные. Бронь сохраняет только ID работы и дату в localStorage; это не реальное резервирование, оплаты нет. QR ведёт на конкретную работу с открытием бронирования. Чтобы включить реальные заявки, нужны сервер, база, правила доступности, уведомления и обработка персональных данных.

Сценарии мерча и тиражной графики остаются за пределами первой итерации.

## Вторая итерация
Тёмная тема, оригинальная анимация материи (MP4 и GIF, статичный постер для reduced motion), шесть вымышленных авторов. Кураторский текст и словарь: Харман, Мортон, Брайант, Богост.

Маршруты: `#/authors`, `#/author/<id>`, `#/work/<id>`, `#/collaboration/<id>`, `#/shop`, `#/collaborations`. Страницы магазина и общего раздела коллабораций — заглушки. Заявки на коллаборацию демонстрационные, не отправляются и не сохраняют персональные данные.

`npm test` собирает проект и проверяет основные сценарии в JSDOM: шесть работ и авторов, словарь, валидацию и подтверждение заявки, заглушки и бронирование по QR-ссылке. Это не визуальная проверка в браузере.

## Проекты и Воркута
Главная страница — каталог из двух проектов. `#/project/ooo` сохраняет первую демо-подборку, `#/project/vorkuta` — «В каждом из нас», куратор Оксана Виноградова. Восемь участников из предоставленного списка. Кураторский текст и даты из материалов пользователя; персональные биографии, цены и авторство конкретных работ не выдумываются.

Обложка адаптирована по присланной афише. Фотографии работ и фрагментов (без людей) с предоставленного альбома: https://aleksandraptitsa.ru/disk/24-09-2026-v-kazhdom-iz-nas-ng6p2m. Ссылки на исходные кадры в `public/vorkuta/credits.json`. Шрифт Cormorant Garamond локальный, лицензия OFL в public/fonts.

Страницы участников `#/author/vorkuta-<id>`, формы заказа `#/order/vorkuta-<id>`. Выставка завершена: вместо бронирования — запрос на приобретение с согласованием цены, доступности и доставки. Контакты художников и получатель заказов не предоставлены, поэтому форма честно готовит скачиваемый черновик без отправки и без хранения персональных данных. Для реальных заказов нужен адрес получателя и обработчик заявок.

## Визуальная система
Общий UI оформлен как панк-зин: лайм, розовый, фиолетовый, рубленая типографика, контрастные границы, смещённые карточки и жёсткие тени. Стили в src/punk.css. Афиша Воркуты и фотографии работ сохранены; формы и навигация используют общую систему. На узких экранах смещения уменьшены, системное reduced motion учитывается.
